# Support

Scenario for Blender is an open-source extension maintained by Scenario. This
page says where to look and whom to ask.

## Using the extension

- Start with the [user guide](docs/USER_GUIDE.md), including
  [Troubleshooting](docs/USER_GUIDE.md#troubleshooting).
- For models, Creative Units and account settings, see the
  [Scenario Knowledge Base](https://help.scenario.com).
- For the Scenario API, see the [API documentation](https://docs.scenario.com).
- For release changes, read the [changelog](CHANGELOG.md) and
  [releases](https://github.com/scenario-labs/blender-plugin/releases).

## Questions and ideas

Discussions are not enabled. Search the
[existing issues](https://github.com/scenario-labs/blender-plugin/issues) and
[known limitations](docs/KNOWN_LIMITATIONS.md) first. For an idea, use the change
request form when available. For a question, open a blank issue with a title
starting with "Question:"; a maintainer adds the `question` label.

## Bugs and change requests

Use the [issue chooser](https://github.com/scenario-labs/blender-plugin/issues/new/choose).
If a form is not available, open a blank issue with the details below.

Before filing a bug, collect:

- Blender version from About Blender, and your operating system.
- Extension version from Edit > Preferences > Add-ons > Scenario, and whether
  you installed a release ZIP, an extension repository package or a source build.
- Steps to reproduce, what you expected and what happened instead.
- Relevant console output: Window > Toggle System Console on Windows, or the
  terminal you started Blender from on macOS and Linux. Extension messages
  contain `scenario`, for example `INFO:scenario.jobs:...`.

Public issues and attachments are visible to everyone. Review logs and screenshots
before posting. Never include an API key, API secret, MCP bearer token, signed
upload/download URL or confidential scene data. Reduce the example to information
that you can share publicly; send sensitive account details through private support.

## Account, billing, credits, API keys and security

Keep these matters out of public issues. Write to
[support@scenario.com](mailto:support@scenario.com) or use in-app support at
[app.scenario.com](https://app.scenario.com).

Report security vulnerabilities through the
[private report form](https://github.com/scenario-labs/blender-plugin/security/advisories/new)
on the repository's Security tab, or email support@scenario.com with "security"
in the subject. Do not post vulnerability details in a public issue.

## What to expect

Extension issues are handled on a best-effort basis, without a response-time
commitment. Support for your Scenario account or subscription goes through the
Scenario channels above.
